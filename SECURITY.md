# Security policy

## Supported versions

The latest code on `main` is supported. Other revisions are not covered by a
security support commitment.

## Report a vulnerability

Report vulnerabilities privately through GitHub's **Report a vulnerability**
link in this repository's Security tab. Do not post vulnerability details in a
public issue, discussion, pull request, or commit.

Include the affected commit or version, the impact, and steps to reproduce the
issue. Remove credentials, real Discord message content, and other private data
from the report. The maintainer will coordinate any public disclosure with the
reporter. No response-time guarantee is offered.
